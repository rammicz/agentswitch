# Native picker, consent and recovery

Plain `agentswitch` uses the read-only Codex, Claude Code, OpenCode and Grok Build adapters, terminal picker, bounded history builder and interactive runtime. The [Antigravity storage profile](agy-reader.md) adds quiescent local public-text histories, incoming/outgoing fresh transfers and sparse last-ID metadata with confirmed empty-request native open. It requires a terminal. `--demo` remains synthetic and launches nothing. The integration tests use offline fixtures and fake executables.

Native roots follow `CODEX_HOME`, `CODEX_SQLITE_HOME` and `CLAUDE_CONFIG_DIR`, with the readers' usual home-directory defaults. OpenCode follows `OPENCODE_DB` and `XDG_DATA_HOME`. Its [exact 1.19.6 profile](opencode-reader.md) requires a stable closed SQLite store with no sidecars and excludes 2.x. Grok Build uses `GROK_HOME` (default `~/.grok`) with a bounded direct read-only [public v1 profile](grok-reader.md). Legacy/unknown storage, relocation and worktree sessions are outside this profile. Antigravity local storage follows `AGENTSWITCH_AGY_ROOT` (default `~/.gemini/antigravity-cli`). Discovery launches no provider. Unknown metadata dates sort last. State goes under `AGENTSWITCH_STATE_DIR`, or `$XDG_STATE_HOME/agentswitch` (default `~/.local/state/agentswitch`). Use a dedicated private directory. Native roots and application state must be separate, including aliases and missing descendant paths. State has separate `search`, `archives` and `transfers` directories. Readers never import, rewrite or delete native history, settings or credentials.

Folder scope matches the canonical workspace exactly. Tab toggles global scope; left/right filters source agents. Queries include public message text. Selected histories are reread before preparation and checked again after final consent. Missing workspaces require W and an explicit valid override. Recorded workspace is the default for a global result. No checkout or files are moved.

The list shows main sessions by default. A parent displays a right arrow and the number of its known direct subagents in the details pane. Press Right to open that list and Left or Esc to return. F3 includes subagents in ordinary search results, and Shift+Left or Shift+Right changes the source filter. The list shows relative last-used times. Where Codex has no saved activity timestamp for a plain rollout, the picker uses the rollout’s modification time. Move the selection to update details with the timestamp, recorded folder and available public excerpts. Narrow terminals stack the details below the list. Enter opens the full preview. Set `NO_COLOR=1` to disable the pastel palette.

The picker opens during discovery and shows results as providers return them. Codex subagents without saved titles use their recorded nickname and role. Recent untitled Codex and Antigravity conversations can use their first public user message. Open a preview to see the full session ID. Press F2 in the session list to see source warnings. A text query reads public messages within its active provider and workspace filters. Global searches can take longer on large histories. The CLI caches complete transcripts that match a text search. If a listed session later becomes unreadable, the cache can still help you find it. Incomplete public history blocks preparation. `agentswitch cache purge` removes retained search data.

After transcript preview, choose a target. C edits the current request (Ctrl+U clears it), X adds a literal redaction, F explicitly requests a fresh context, and W overrides the workspace. Default current request is “Continue the task from this conversation.” Redactions replace matches before retained transfer content is built. Routing IDs and storage/workspace paths must stay exact; a redaction overlapping one is rejected before publication. Redactions do not erase original native history or the independently purgeable search cache.

The final scrollable preview names source, target, mode, workspace, included/omitted IDs, archive reference, target-provider disclosure and the exact wire value as a JSON string between explicit begin/end markers. Decode that displayed JSON string once to recover the exact prompt; literal backslashes remain distinct from visibly escaped controls. Printable Unicode stays readable, while C1 controls, bidi controls and Unicode line separators are escaped. Scrolling preserves every code point, with conservative terminal-cell wrapping; the wire schema and byte budget are unchanged. Ordinary Codex/Claude native resume sends only the redacted new request, using the exact native UUID. OpenCode opens its exact `ses_` session without an automatic request: clear the draft explicitly, then type in the native client. Grok likewise opens only the exact UUID in its recorded canonical workspace with an explicitly cleared draft and no automatic request. A nonempty draft remains available for F fresh context; W override uses fresh mode. A compatible earlier Codex target can instead receive its exact missing eligible history; the summary names its independent native UUID. See [continuity](continuity.md) for hook trust, provenance and conservative fallback rules. Fresh handoff sends attributed historical public messages plus a separate request once, under the target's own account and permissions. Hidden reasoning, credentials and approval state do not transfer. Capability probes use only `--help`/`--version`; confirmation is required before publishing the redacted archive or launching an interactive target. Cancelled drafts remain in memory only. Executable/workspace identity changes fail safely; source changes require a new preview.

The launcher supports the pinned versions in [runtime.md](runtime.md). agentswitch neither installs nor authenticates providers. Target prompts are bounded to 16,384 UTF-8 bytes; argv is locally observable under OS rules. Whole omitted messages remain in the approved private archive, accessible through the displayed `archive list/read` commands. Ordinary request-only native resume creates no historical archive; a missing-history native resume retains its approved delta archive.

## Journal and ownership

A versioned private SQLite journal uses FULL synchronous transactions, exclusive source admission and an independent scoped reservation for an actual resumed target. It records immutable attempt UUID, source/root digest and native identity, target provider, mode/workspace, exact consented redacted prompt and its SHA-256, archive reference, included/omitted IDs, completeness, timestamps, launch/writer evidence, exit details and actual target native ID when known. It never retains redaction selections, original drafts, provider environment, executable argv copies or hidden data. Deletion uses secure SQLite page deletion, without promising physical disk erasure.

`prepared` is consented intent, `pending` is committed before any possible spawn, `uncertain` means no trustworthy consumption receipt, and `failed` means the attempt definitely failed before dispatch. `accepted` is available only through the trusted programmatic receipt boundary, correlated to attempt UUID, payload hash, target provider and actual target session identity. The default CLI conditionally observes matching Codex submit/successful main Stop hooks under native enablement, trust and managed policy; Claude, OpenCode, Antigravity and Grok Build have no exact-turn receipt adapter. Exit 0, nonzero exit, signal, PID observation and the PTY test's termios ACK never establish consumption. Receipt and exact selected coverage commit atomically; absence of a supported receipt never advances coverage.

Ownership is independent. Pending intent reserves its canonical source before archive publication/spawn. A normal supervised target close atomically records stopped writer evidence and releases only that attempt's source admission, leaving delivery uncertain. An intentional new selection can then proceed with a new preview and confirmation. Receipt alone cannot release a writer. Wrapper death, absent PID, aged records, parent exit, abort and restart never prove the child stopped or release an unresolved reservation. No native writer is automatically taken over, and no stored prompt is automatically launched. This coordinates agentswitch-owned writers; arbitrary external native clients and provider descendants are not universally detectable or supervised.

An archive gets a durable per-attempt use pin before launch. Direct `archive delete` also refuses pinned references. Normal supervised close releases the pin. After an ambiguous wrapper crash, the pin and native source reservation remain, including the spawn-before-PID gap. Unknown writers cannot be purged through recovery; a missing parent PID is insufficient evidence. Fresh context recovery remains possible without touching the native source. This conservative refusal can retain artifacts indefinitely after an unobservable crash.

## Explicit controls

```sh
agentswitch transfers list
agentswitch transfers show <attempt-uuid>
agentswitch transfers retry <attempt-uuid>
agentswitch transfers abort <attempt-uuid>
agentswitch transfers delete <attempt-uuid>
agentswitch cache purge
```

`list` reports state/identity/evidence without prompt content. `show` explicitly returns the consented redacted prompt for review. `retry` opens the picker on the retained redacted snapshot and current request (native-resume records have no archive, so they reread current public native history for a new review/redaction), discloses possible earlier delivery, forces a fresh target context and creates a new attempt only after renewed confirmation. It never reuses the old launch plan. Antigravity cache-only native opens cannot be retried as a fresh transcript; reselect the exact metadata entry and confirm a new native open instead. A new recovery attempt has its own atomic admission; competing retries of one attempt cannot launch concurrently.

`abort` retires an attempt without changing its historical outcome, killing a target or releasing unknown ownership. `delete` is explicit and allowed only for prepared/failed or retired supervised-stopped attempts. Transactional deletion admission prevents a concurrent launch before removing the archive and journal prompt. It removes matching archive crash leftovers and retained content, invalidates retrieval and linked continuity reuse, and leaves a minimal non-sensitive tombstone. Linked unknown writers also prevent deletion. A crash during deletion can be completed by repeating deletion; no replay becomes available. Unknown active archives remain protected.

`cache purge` separately removes derived searchable public text. It does not delete native histories or transfer archives. File deletion cannot recall target-provider data or previously returned/in-flight archive pages, and does not promise physical erasure.

All automated integration tests use synthetic native roots and fake executables. They cover both handoff directions, same-agent resume/reuse, exact consented redaction, scope/filter/workspace behavior, cancellation, changed inputs, archive omissions/retrieval, concurrent CLI processes, wrapper crashes with a live child (including no persisted child PID), receipt correlation, journal restart and private artifact deletion. No account data, real histories or model calls are used.
