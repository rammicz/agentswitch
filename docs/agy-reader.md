# Antigravity CLI local public-text profile

Google Antigravity CLI (`agy`) **1.5.14** supports reviewed incoming and outgoing fresh handoffs from a bounded local public-text storage profile. The picker searches eligible public user/assistant text and reads sparse last-ID metadata when a full catalog is absent. Same-agent native open sends no initial request. The source profile matches storage observed from the exact native binary against a synthetic loopback mock. Real Google-account authentication and external provider consumption remain unverified.

## Local metadata and native open

Sparse metadata fallback reads `~/.gemini/antigravity-cli/cache/last_conversations.json`. This JSON object maps absolute workspace paths to last conversation IDs, as described in Google's [resume documentation](https://antigravity.google/docs/cli/commands/resume). `AGENTSWITCH_AGY_ROOT` overrides the `antigravity-cli` directory for agentswitch. The programmatic `root` option takes precedence. This setting controls the agentswitch read root. Native configuration overrides are separate. No behavior is inferred from `GEMINI_HOME`.

The sparse cache reader accepts UUID IDs and canonicalizes workspace aliases. Other ID formats are unsupported. Each display title says “metadata only”. The cache contains no native title, timestamp, producer version, transcript or complete session inventory. `updatedAt: ''` represents an unknown date and sorts after dated sessions. Search reaches cache IDs and workspaces. Native message text remains unavailable. Ambiguous ID/workspace mappings are excluded, malformed siblings get bounded diagnostic codes, and a missing workspace remains unavailable for native open. Defaults cap the single file at 1 MiB, 1,000 entries and 100 diagnostics. Symlink escapes, symlink leaves, oversized or changing files are refused. Native bytes are never rewritten. Discovery and index queries spawn no provider and make no network requests.

To open a listed agy conversation, choose agy, press C and explicitly clear the draft with Ctrl+U. Confirm the summary. The native argv is `['--conversation', exactId]` in its recorded canonical workspace. Workspace overrides, nonempty requests, redactions and fresh/outgoing operations from cache-only sources are refused. agy revalidates its account and native identity. It may show its home or a fresh context if the cached conversation is unavailable. Agentswitch sends no prompt, chooses no replacement ID and attempts no second launch. Type the next request in the native client after checking its identity.

The shared journal prevents overlap with unresolved agentswitch-owned writers, including crashed unknown writers. Other native clients cannot be universally detected. Stop concurrent writers first. Native active-session handling, project association, account policy and approvals remain with agy. Cache provenance supplies a resume candidate. Confirm the actual opened context in the native client. This launch records unknown history completeness, no history archive, no retained continuity coverage and no trusted consumption receipt. A cache-only native attempt cannot be retried as a fabricated fresh transcript.

## Quiescent local history

Under the configured root, `conversation_summaries.db` supplies named identity, workspace, recency and safety columns from `conversation_summaries`. Native title, preview, opaque blobs and private conversation databases are excluded. Catalog titles use a bounded first public user line after successful hydration, with the native UUID as fallback. Discovery reads catalog metadata without eagerly loading transcripts. Histories are loaded lazily from `brain/<UUID>/.system_generated/logs/transcript.jsonl` and hydrated for public-text search by the catalog.

The SQLite table must contain every selected column, with `conversation_id` as primary key. Columns added by later releases and unselected columns are ignored. The file is opened with `mode=ro&immutable=1` after bounded path and sidecar checks. Summary and selected conversation WAL/SHM/journal/master-journal files, symlinks, unsafe aliases, changing snapshots and active or unknown status are refused. The row must report idle status, `killed: 0`, `not_fully_idle: 0`, a supported local identity and a completed step count that matches the transcript. A transcript exactly one step shorter than that count, with contiguous indexes from 0, is the writer not having appended its last step yet: it reads as present with a non-blocking `step-count-lag` note, which does not mark the source degraded. Any other count mismatch or index gap is `invalid-ordinal`. Known invalid rows never downgrade to cache-only entries. Stop native writers before reading. Quiet filesystem checks establish a bounded snapshot, and unrelated clients can still write later.

A single local absolute `file:` workspace URI is authoritative. An empty URI field can use exactly one agreeing last-ID cache mapping, as demonstrated by the native interactive fixture. Conflicting, ambiguous or missing mappings are refused. Folder search uses its canonical workspace. No workspace is inferred from prompt text, titles or the current picker folder.

Only `USER_EXPLICIT` / `USER_INPUT` and public `MODEL` / `PLANNER_RESPONSE.content` are projected, in exact `step_index` order. Each turn must include a completed user request and at least one assistant response; a turn may hold several assistant responses between tool steps. Native metadata/settings wrappers and separate `thinking` fields are excluded. Unknown top-level transcript keys from later releases are ignored and never projected, while known fields keep their type, ordinal, status and timestamp checks. Nested or ambiguous wrapper delimiters, unknown types, known fields in an unexpected record kind, unknown nested tool fields, controls, gaps, missing lines, incomplete steps and truncated captures fail closed. Stable public IDs bind the native UUID, observed step, role and public text. A private snapshot signature participates in dispatch revalidation. Native retention and trusted consumption remain unavailable.

Tool and system steps are excluded steps. A `PLANNER_RESPONSE` with `tool_calls` (one or more `{name, args}` calls, any tool name, for example `run_command`, `read_file`, `write_file`, `edit_file`, `invoke_subagent`, `define_subagent`, `send_message`, `manage_task` or `schedule`) is followed by one `GENERIC` / `MODEL` result step per call; a result may be `DONE`, `RUNNING`, `ERROR` or `INVALID`. `SYSTEM_MESSAGE` / `SYSTEM` steps are excluded wherever they occur. Arguments, result bodies and system text never enter search, preview, archive or handoff; public `content` on a tool-call step is still projected. Final confirmation discloses the excluded native step indexes. Unknown step types and sources, a result without its call, a missing result, an unknown result status, other non-`DONE` steps and malformed calls still fail closed. `complete` describes the reviewed public user/assistant text projection, including accounted exclusions. It does not certify raw native or tool-history completeness. Unsupported carriers refuse outgoing transfers. The archive retains every eligible public item, with ordinary whole-item budget omissions and retrieval references. Redactions apply before archive publication. The same confirmed flow supports agy→Codex and agy→Claude Code, cancellation and explicit uncertain-delivery recovery.

Defaults bound the database to 64 MiB, each transcript to 32 MiB, each JSONL line to 1 MiB, a refresh generation to 256 MiB, catalog/cache entries to 1,000, transcript steps to 100,000, each directory inventory to 10,000 entries and diagnostics to 100. The sparse cache is capped at 1 MiB. Configurable limits may only lower these bounds. Healthy siblings survive unsupported records. Selected snapshots recheck native file identity, activity and omission semantics before dispatch. No reader starts agy, requests an account, uses ACP or copies credentials.

## Incoming fresh transfers

The runtime accepts any version whose help lists the flag the launch passes: `--prompt-interactive` for a fresh handoff, `--conversation` for native open (tested with `1.5.14`). A reviewed fresh handoff uses `['--prompt-interactive', completeJsonEnvelope]`, inherited terminal and the approved canonical cwd. Its single payload remains bounded to 16,384 UTF-8 bytes with whole-message omissions and a usable private archive. Cancelled confirmation creates no transfer archive or journal attempt. Literal arguments use `shell: false`. No permission, model, remote, project, login or automatic approval flags are added. Native settings and credentials remain native.

Like other argv transports, the payload may be visible in local process inspection. The target uses its own native account and instructions. Exit status never proves consumption or target identity. Uncertain incoming delivery survives restart and requires an explicit fresh retry. No agy receipt adapter can advance accepted coverage.
